    Publish your changes

    Everything you change here is saved in this browser first, so you can check it on the shop. Press Publish to website when you are happy and everyone will see it within 1–2 minutes.

    One-time setup

    Publishing needs a GitHub access key. You only do this once on each computer:

    1. Open GitHub → new access token and sign in.
    2. Name it ZipZapBags dashboard and choose the longest expiry.
    3. Under Repository access pick Only select repositories and choose your website repository.
    4. Under Repository permissions set Contents to Read and write.
    5. Click Generate token, copy it, paste it below and press Save setup.

    The token stays only in this browser. Never share it with anyone.

    Change dashboard password

    Choose a password only you know (at least 8 characters). Press Publish afterwards so it works on every computer.

    Prefer to upload manually?

    Download the updated website file and upload it to GitHub yourself as index.html.
